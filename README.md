# Планировщик задач (Todo List)

Выпускной проект: Планировщик задач с возможностю редактирования как содержания задач, так и графика их повторения, с реализацией аутентификации, в Docker-контейнере.

## Описание
Веб-приложение для управления задачами с аутентификацией. Реализовано на Go. Данные хранятся в SQLite базе данных. Приложение упаковано в Docker-образ.

## Дополнительные условия согласно заданию
Были выполнены все задания со звёздочкой.

## Особенности содержимого
Реализована проверка наличия переменной окружения с паролем при запуске приложения.
Для расчёта даты следующего события реализована добавочная функция "calculatedYearAndDay" для просчёта текущего года и количества дней в переданном месяце, для проверки валидности переданной даты.
Также реализована потенциальная возможность составления списка дат, согласно требуемому условию повторения для теоретического добавления ряда заданий в общий график (закомментирована как потенциальная, однако не отвечающая логике требованиям задания).
Реализована возможность редактирования содержания задачи без изменения критических позиций(дата, повторения), путём добавления функции "ChangedDate".

В проекте задействуются переменные окружения: TODO_PORT, TODO_DBFILE, TODO_PASSWORD, JWT_SECRET, а также isSecure := os.Getenv("APP_ENV") == "production" - для установки статуса для Cookie (production или development).
Имеется файл конфигурационный файл .env.example.

export TODO_DBFILE="./scheduler.db" 
export TODO_PASSWORD="1"
export JWT_SECRET="practicum"
export APP_ENV="development"
